# CodeAlpha Social Media App

## Project Overview
This is a Django-based social media web application developed as part of the CodeAlpha Full Stack Development Internship.

## Features
- User Registration and Login
- Create and View Posts
- Like and Comment on Posts
- User Profile and Bio Editing
- Follow and Unfollow Users

## Technologies Used
- Python
- Django
- SQLite
- HTML
- CSS

## How to Run
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run database migrations using `python manage.py migrate`.
4. Start the server using `python manage.py runserver`.
5. Open `http://127.0.0.1:8000/` in your browser.
